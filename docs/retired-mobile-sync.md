# Clean up a retired Mobile Sync installation

[Türkçe](#türkçe)

Mobile Sync and the self-built iPhone companion have been removed from the current source. These steps apply if you previously set up the companion.

1. **Remove the Mac's old route first.** Quit any older UsageBar or standalone Mobile Host copy. On the Mac, run `tailscale serve status` and find the old UsageBar route to `http://127.0.0.1:18642`. If that is the root path on HTTPS port 443, the standard setup, remove that route with `tailscale serve --https=443 --set-path=/ off`. For another port or path, use the matching flags from the [Tailscale Serve documentation](https://tailscale.com/docs/reference/tailscale-cli/serve#disable-tailscale-serve). Recheck status and confirm other routes are intact. If the route is absent, skip this step. A blanket Serve reset would remove other services as well.
2. **Clear the old iPhone connection.** If UsageBar Mobile is still installed and shows a saved connection, choose **Forget**, then **Forget Connection**, before removing the app and its widgets and controls. That action clears the saved connection and snapshot cache. If the app was already removed, the Keychain item can survive. To clear it on the phone, use only your own trusted build with the original team, bundle identifier and Keychain access group. After removing the route, disconnect the phone from the network, use **Forget Connection**, then remove the app again.
3. **Remove the exact Mac Keychain entry.** In Keychain Access, find the generic password with service `local.codex.usagebar.mobile-sync` and account `mobile-auth-v1`. Verify both fields before deleting the entry. Leave other entries, including `Claude Code-credentials`, in place. If the entry is absent, skip this step. If you used the separate Mobile Host 0.1.0, check its distinct service `com.usagebar.mobilelab.host.mobile-sync` as well. Delete only the entry you can identify as that host’s pairing record.

The new Mac app removes the retired preference from its current domain and excludes it from the one-time import of the old domain. It preserves the old domain for older builds. If you keep an old copy for rollback, leave it closed. With it closed, you can clear just the old flag with `defaults delete local.codex.usagebar MobileSyncEnabled` if that key exists.

## Türkçe

Mobil Eşitleme ve iPhone eşlikçi uygulamasının kaynak kodu güncel sürümden kaldırıldı. Eşlikçi uygulamayı daha önce kurduysanız şu adımları izleyin.

1. **Önce Mac'teki eski rotayı kaldırın.** Açık olan eski UsageBar veya ayrı Mobile Host kopyalarını kapatın. Mac'te `tailscale serve status` çalıştırıp `http://127.0.0.1:18642` hedefine giden eski UsageBar rotasını bulun. Standart kurulumdaki gibi HTTPS 443 üzerinde kök yolsa `tailscale serve --https=443 --set-path=/ off` ile bu rotayı kapatın. Farklı port veya yol için [Tailscale Serve belgesindeki](https://tailscale.com/docs/reference/tailscale-cli/serve#disable-tailscale-serve) eşleşen seçenekleri kullanın. Durumu tekrar kontrol edip diğer rotaların korunduğunu doğrulayın. Rota yoksa bu adımı atlayın. Genel Serve sıfırlaması diğer hizmetleri de kaldırır.
2. **Eski iPhone bağlantısını silin.** UsageBar Mobile hâlâ kuruluysa ve kayıtlı bir bağlantı gösteriyorsa, uygulamayı ve widget/denetimlerini kaldırmadan önce **Forget**, ardından **Forget Connection** seçin. Bu işlem kayıtlı bağlantıyı ve anlık görüntü önbelleğini temizler. Uygulamayı daha önce sildiyseniz Anahtar Zinciri kaydı kalmış olabilir. Telefondaki kaydı temizlemek için yalnızca kendi güvenilir derlemenizi, özgün imzalama ekibi, paket kimliği ve Anahtar Zinciri erişim grubuyla kullanın. Rotayı kaldırdıktan sonra telefonu ağdan ayırın, **Forget Connection** seçin ve uygulamayı tekrar kaldırın.
3. **Mac'te yalnızca ilgili Anahtar Zinciri kaydını silin.** Anahtar Zinciri Erişimi'nde hizmeti `local.codex.usagebar.mobile-sync`, hesabı `mobile-auth-v1` olan genel parola kaydını bulun. Silmeden önce iki alanı da doğrulayın. `Claude Code-credentials` dahil diğer öğeleri koruyun. Kayıt yoksa bu adımı atlayın. Ayrı Mobile Host 0.1.0 kullandıysanız onun `com.usagebar.mobilelab.host.mobile-sync` hizmetini de kontrol edin. Yalnızca o uygulamaya ait eşleşme kaydı olduğunu doğruladığınız öğeyi silin.

Yeni Mac uygulaması kaldırılan tercihi güncel alandan temizler ve eski alandan yapılan tek seferlik kopyaya almaz. Eski tercih alanı eski sürümler için korunur. Geri dönüş için eski bir kopya tutuyorsanız kapalı bırakın. Eski kopya kapalıyken, anahtar mevcutsa yalnızca eski mobil ayarı `defaults delete local.codex.usagebar MobileSyncEnabled` ile kaldırabilirsiniz.
